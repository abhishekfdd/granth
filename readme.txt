A block theme for documentation and knowledge base sites.

== Description ==

Granth is a block theme built for documentation, handbooks and knowledge bases. The docs sidebar is generated from your page hierarchy, so organizing your content is as simple as arranging parent and child pages. A search-first front page, callout box styles for notes, tips and warnings, careful long-form typography with Figtree, and code typography with JetBrains Mono round out the toolkit. Two style variations are included: Midnight (dark) and Parchment (warm). Everything is built with core blocks and can be customized in the site editor.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

== Frequently Asked Questions ==

= How do I get the docs sidebar to show my pages? =

Publish your pages and arrange them with parent/child relationships under Page Attributes. The sidebar picks up the hierarchy automatically. To curate the list instead, select the Navigation block in the Docs Sidebar template part and assign a menu.

= How do I write a page without the sidebar? =

Edit the page and choose the "Page (No Sidebar)" template in the page settings panel.

= Does this theme require any plugins? =

No. Everything works with WordPress core.
